# ZTWIM Testing Guide

## Test Suites

| Suite | Location | Framework | Run Command |
|---|---|---|---|
| Unit tests | `pkg/controller/*/` | Go `testing` + counterfeiter fakes | `make test` |
| Utility tests | `pkg/controller/utils/` | Go `testing` | `make test` |
| E2E tests | `test/e2e/` | Ginkgo v2 + Gomega | `make test-e2e` (requires cluster) |

## Unit Test Pattern

Unit tests use **counterfeiter-generated fakes** for the `CustomCtrlClient` interface, NOT envtest or a real API server.

### Test setup pattern (`pkg/controller/spire-server/controller_test.go`):

```go
func newTestReconciler(fakeClient *fakes.FakeCustomCtrlClient) *SpireServerReconciler {
    return &SpireServerReconciler{
        ctrlClient:    fakeClient,
        ctx:           context.Background(),
        log:           logr.Discard(),
        scheme:        runtime.NewScheme(),
        eventRecorder: record.NewFakeRecorder(100),
    }
}
```

### Key testing patterns

1. **Fake client setup**: Configure `FakeCustomCtrlClient` method stubs (e.g., `fakeClient.GetReturns(notFoundErr)`)
2. **Error simulation**: Use `kerrors.NewNotFound()`, `kerrors.NewConflict()`, etc. to simulate API errors
3. **Status verification**: Check conditions on the CR status after reconciliation
4. **Resource comparison tests**: `pkg/controller/utils/resource_comparison_test.go` tests `ResourceNeedsUpdate()` for each resource type

### Fake client interface (`pkg/client/fakes/`)

Generated by counterfeiter from `CustomCtrlClient` interface:

```go
//go:generate go run github.com/maxbrunsfeld/counterfeiter/v6 -generate
//counterfeiter:generate -o fakes . CustomCtrlClient
```

Available fake methods: `GetReturns()`, `CreateReturns()`, `UpdateReturns()`, `GetCallCount()`, `GetArgsForCall()`, etc.

To regenerate: `go generate ./pkg/client/...`

## E2E Tests

Located in `test/e2e/`, using Ginkgo v2 framework:
- `e2e_suite_test.go` — suite setup
- `e2e_test.go` — end-to-end test scenarios (~1934 lines)

E2E tests require a running OpenShift cluster with the operator deployed.

## Writing New Tests

1. **Unit tests**: Use the counterfeiter fake pattern. Create a `newTestReconciler()` helper, configure fake method stubs, call `Reconcile()`, assert results.
2. **Add test file**: Place in the same package as the code under test (e.g., `pkg/controller/spire-server/`).
3. **Run**: `make test` runs all unit tests. For a specific package: `go test ./pkg/controller/spire-server/...`
